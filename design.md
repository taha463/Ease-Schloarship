# Design — Ease Scholarship

The shared visual system for the scholarship intelligence dashboard.

## Genre
Editorial Garden: quiet, evidence-led, warm paper, botanical ink.

## Structure
- App pages: workbench layout with a masthead shell and hairline panel rhythm.
- Primary axis: left-biased content with generous negative space.
- Hero treatment: oversized roman serif page heading, short sans-serif context.

## Theme
- Paper: `oklch(97% 0.012 92)`
- Ink: `oklch(20% 0.025 150)`
- Rule: `oklch(86% 0.018 92)`
- Accent: `oklch(41% 0.105 150)`
- Signal: `oklch(63% 0.145 48)`

## Typography
- Display: DM Serif Display, roman.
- Body: Plus Jakarta Sans.
- Use display type for page and section headings; use body type for controls and evidence.

## Brand
- Wordmark: Ease Scholarship.
- Mark: a single serif capital `E`, used in the header and browser favicon.

## Interaction
- Hairline borders instead of stacked cards and shadows.
- Controls use compact square corners.
- Accent is reserved for active navigation, evidence status, focus, and primary actions.
- Reduced motion collapses to opacity-only transitions.
